## Weather Data Analysis

## Project Overview

This project analyzes climate and weather data from multiple cities in Pakistan using Python. The analysis explores weather patterns, data quality, city-wise distributions, and trends through data cleaning, statistical analysis, and visualization.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis Performed

* Cleaned and prepared weather data for analysis
* Handled missing and inconsistent values
* Analyzed weather data across different cities
* Explored date-based weather patterns
* Compared weather-related measurements across cities
* Created visualizations to identify patterns and trends
* Used statistical analysis to generate meaningful insights

## Key Skills Demonstrated

* Data Cleaning
* Exploratory Data Analysis (EDA)
* Data Visualization
* Statistical Analysis
* Python Data Analysis
* Pandas & NumPy
* Data Interpretation
## Key Findings

* The dataset contains **31,779 weather records** collected across multiple cities in Pakistan.
* Weather data covers the period from **2000 to 2024**.
* **Islamabad** had the highest number of records, followed by Karachi and Peshawar.
* Data cleaning was performed to identify and handle missing and inconsistent values.
* The `visibility` column was removed because it contained missing values for all records.
* City-wise and time-based analysis was performed to identify patterns and differences in weather data.
